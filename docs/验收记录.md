# 功能与验收记录

**班级积分（加分）系统**，Windows 桌面应用（WinUI 3）。同一个 exe 三种形态 —— 教室大屏、班主任电脑、只读查询，
首次启动向导里选定，另有可选的云端同步中枢。这一份记录了这个版本包含什么、逐项验过什么、哪些地方是刻意不做。
设计依据：`docs/班级积分系统-方案v2.md`（v2.5）。

## 二、功能对照（按方案第 9 章）

### 大屏端

| 页面 | 实现要点 |
| --- | --- |
| 看板 | 前 15 名积分榜 + 最近动态 + 今日冠军；名次变化用真实色板（加分红 / 扣分绿），15 秒轮播刷新 |
| 记分台 | 8 列 × 6 行 = 48 人一屏，卡片字号 20 / 积分 36；支持长按拖拽框选多人；点人 → 选加分项 → 落下；键盘 P 进管理模式 |
| 事件计数 | 一格一个学生，大号次数 + 加减两颗 52 高按钮（加是实心强调色，减是描边）；顶部事件胶囊带全班次数；右上「撤销上一步」 |
| 查分 | 按学号或姓名即时过滤，11 列网格，个人明细可展开 |
| 明细 | 只看当天；**未认人时整列隐藏「操作人」**（教室是公开屏幕），认人后显示；左滑撤销 |
| 设置 | 七节：班级、密码与恢复码、班委与卡、加分项、座位布局、显示、退出 |

### 电脑端

| 页面 | 实现要点 |
| --- | --- |
| 总览 | 四个数字卡（今日发放 / 学期累计 / 在册学生 / 本学期考试）+ 最近 12 条 + **「需要处理」清单**（无名单、久未备份、权重未配平、缺考未处理、无成绩、无恢复码） |
| 名单 | 搜索；粘贴一列姓名（**自动去「1、」「03 」这类序号前缀**）；Excel/CSV 导入带列映射；新增/编辑/停用；座位布局；回收站 |
| 事件计数 | 学生 × 事件矩阵，每格「− 次数 +」，点数字直接改成准确次数（补差额流水）；右侧最近流水可核对；新增/改名/停用事件 |
| 成绩 | 考试增删改；两层权重（平时分 : 考试分）+ 各场权重滑块与数字框 + 自动配平；口径（是否归一百分制 + 缺考三策略）；排名预览；导入 xlsx 带逐行状态与「加入名单」；导出前检查 |
| 打印 | 五种版式（排名表 / 总评表 / 个人成绩单 / 恢复卡 / 归档封面），左选版式右预览（所见即所印），打印机下拉 + 无页眉页脚直打，或另存 HTML |
| 周期 | 当前周期四项数字；两种重置（重置积分：term_key 不变；重置学期：term_key 重开，需长按 3 秒 + 输入「确认重置」）；历史周期看榜单/导出 |
| 设置 | 八节：班级信息、密码与恢复码、班委、加分项（含恢复预设预览）、备份与恢复、**这台电脑**（当前形态 / 切换为三形态 / 重新运行首次配置）、**同步**、其它 |

### 只读查询端

| 页面 | 实现要点 |
| --- | --- |
| 查分 | 左名单右档案；档案含本周期积分、学期累计、本周期事件次数与事件条目、积分明细 |
| 排名 | 本周期 / 学期累计两种口径切换，带搜索与事件次数列 |
| 事件 | 学生 × 事件的只读矩阵，没有加减按钮 |

这一端**没有任何写入口**：不建会话、不启读卡器、不写库，同步泵只拉不推。
顶部是三个页签（第三种形状），和另外两端一眼能区分。

### 首次启动向导

按形态动态拼步骤：**选形态 → 预配置 →（大屏：班级 / 名单 / 分值 / 建班认人；电脑端：班级；只读端：数据）→ 自检**。
电脑端 4 步、大屏 7 步。

- 形态和配置包都在这一步问，不再走命令行参数；选完写进 `settings.app_mode`，下次启动直接进对应外壳。
- **「完成」之前一个字节都不写库**（配置包除外 —— 那是老师明确点了「套用」才落盘），
  全程在内存里攒，点完成才一次性落盘，半路退出不会留半个班。
- 自检页用真实学生卡渲染，判词按 `ScrollableHeight` 判断「48 人一屏放得下」还是「要不要改少一列」。

## 四、过程中修掉的真实缺陷

这些不是编译问题，是会真出事的：

1. **撤销行没写 `reverses_entry_id`** —— 界面靠它判「已撤销」，`uq_entries_reversal` 靠它防重复撤销，
   同步靠它让另一端认出来。三处全靠这个字段，漏写等于撤销功能半残。已修 `Sql.InsertEntry` 与入账参数。
2. **拉取远端 active 周期时撞唯一索引** —— 本地已有 active 周期时远端那个进不来（`uq_period_active` 全局唯一）。
   改为：远端说谁是当前周期就以远端为准，先把本地那个归档。
3. **HTTP 响应体没读完就 Dispose** —— 连接处于半关闭状态，下一个请求复用会被服务端打断，
   表现为莫名其妙的 500。已改为每次都读掉响应体。
4. **.NET 默认继承系统代理** —— 走代理时请求行变成绝对 URI（`POST http://host/path`），
   Cloudflare 边缘与 `wrangler dev` 都只认 origin-form，直接 500。已默认 `UseProxy=false`，
   确需代理时用 `CP_SYNC_PROXY` 显式指定。
5. **WebView2 未关闭导致退出崩溃** —— 进程内浏览器不显式 `Close()` 会在 COM 终结器里 `0xC0000005`。
   打印页在 `Unloaded` 里关闭，退出前先离开打印页。
6. **打印页 `NavigateToString` 早跑** —— `_ready` 在 `await EnsureCoreWebView2Async()` 之前就置 true，
   报「valid CoreWebView2 is not present」。改为 await 成功后才置位。
7. **粘贴名单不去序号** —— 老师粘「1、张三」会得到叫「1、张三」的学生。新增 `NameNormalizer.StripListIndex`，
   粘贴与 Excel 导入两个入口都接上，并且用测试钉住「3班张三」不被误伤。
8. **向导第 5 步判词说反话** —— 自算像素不可靠，改判 `ScrollableHeight <= 1` 并等布局完成。
9. **D1 多班数据泄漏（最严重的一个）** —— 初版建表时业务表**一张都没带 `class_id`**，所有唯一约束都是全局的。
   放在「一个库一个班」的假设下能跑，一旦同一台共享 D1 上开第二个班，B 班的 `/sync` 能拉到 A 班的流水。
   已重写 `0001_init.sql`：每张表加 `class_id`，`uq_students_no` 等唯一约束全部改成班内唯一，
   全部路由与同步按令牌里的班级收口，并补了 17 项跨班冒烟用例钉住。
   顺带把越权语义从 403 改成「看不见」——跨班删改返回 200/404 而不是 403，403 等于确认「这个 id 存在」。
10. **发布出来的一双击就 `XamlParseException`** —— `csproj` 里 `EnableMsixTooling=false` 导致 MSIX 公共 targets 不导入，
    `AddProjectPriToResolvedFileToPublish` 不存在，`dotnet publish` 出来的目录里没有 `ClassPoints.pri`。
   阴险之处是 `dotnet build` 的产物完全正常，只有 publish 的坏，一度被误判成 PRI/XBF 缓存陈旧。
   已改回 `true`，并在 `publish.ps1` 里加了硬性校验（缺 pri 直接抛错）。
11. **CNB 版本库把仓库容量吃满** —— 每个版本挂一个 70 MB 的 zip，攒十几个就是 1 GB。
    CI 每次 `main` 构建后自动跑 `scripts/prune-cnb-releases.sh`：只留最近 3 个大版本（`v1.2` 这种）
    和固定覆盖的 `latest-build`，其余一律删。清理失败不判红（附件已传好，能下载才是重点）。
12. **CNB 流水线红色但其实测试全过** —— `wrangler dev` 是常驻进程，阶段脚本跑完它还活着，容器等子进程退出等到 600 秒超时。
   已在阶段脚本里加 `trap 'kill -TERM $WDEV' EXIT` + 末尾显式 kill，并把冒烟用 `timeout 240` 包住。
13. **上传到 CNB 明明成功了，CI 却判红** —— 附件已经落库（75.9 MB / 13 秒），
    最后一步生成版本描述时 python 往 stdout 打含中文的 JSON，GitHub 的 windows runner
    默认代码页是 cp1252，直接抛 `UnicodeEncodeError`，`set -e` 把整步算失败。
    修法：脚本里 `export PYTHONIOENCODING=utf-8`、`json.dumps(ensure_ascii=True)`，
    并把「更新描述」降级成失败只提示 —— 附件才是要紧的东西。
14. **`npm ci` 因镜像站故障让 CI 变红** —— `package-lock.json` 里 106 条 `resolved`
    全钉在 `registry.npmmirror.com`（当初本地装依赖时走的镜像），而 CI 在美国，
    本该直连官方。镜像报 `ER_NO_SUCH_TABLE` 时整条 worker 流水线就挂。
    已把 lock 改回官方源，`.cnb.yml` 里再用 `npm config set registry` 指回镜像 ——
    npm 会自动替换 host，两边共用一份 lock。
15. **Excel 里的分数导入进来全是空白（不报错）** —— NPOI 从 2.7.2 升到 2.8.1 之后暴露的：
    2.8 起数值格式化交给 SkiaSharp，而它作为传递依赖在 net10.0 上只给编译期 `ref`、
    运行期资产是空占位，`SkiaSharp.dll` 不进输出目录。`DataFormatter` 抛 `FileNotFoundException`，
    被 `CellText` 的 `catch` 吞成空串 —— 表现是「名单读进来了，分数一栏全空」，且没有任何报错。
    修法是在 `ClassPoints.Data.csproj` 里显式引一次 `SkiaSharp`；同时补了 17 项 Excel 往返用例把它钉住
    （升版前这条链路上一个测例都没有）。
16. **`db:reset` 在 Windows 上删不掉** —— `.wrangler/state` 被 `workerd.exe` 占着，强删半途失败留下残缺目录。
   改成 `renameSync` 挪到 `.wrangler/state.old-<时间戳>`，并先去检查有没有残留的 `wrangler dev`。

## 五、已知限制

1. **本机看不到窗口画面**（远程会话 + 虚拟显示器 + Intel UHD 630，WinUI 3 合成器不呈现）。
   已把 TFM 从 26100 降到 19041、WinAppSDK 从 2.6.5 降到 1.8 各试一遍，均无效，已回滚。
   连最小 `Grid + TextBlock` 都不显示而视觉树与自渲染截图完全正常，判定为环境限制，换真机即好。
2. **打印没有系统打印对话框**：WinUI 版 WebView2 没有 `ShowPrintUIAsync`（WPF/Win32 专有），
   改为「选打印机 + 无页眉页脚直打」。纸张、边距由 `CoreWebView2PrintSettings` 控制。
3. **读卡器只支持 PN532 串口**，含模拟刷卡调试通道；没做 ACR122U 等 PC/SC 读卡器。
4. **PDF 不直出**：报告单导出 xlsx；要 PDF 走「打印 → Microsoft Print to PDF」。
5. **同步不含文件存储**：只同步结构化数据，头像/照片没有。R2 凭据已备，要托管制品需单独接。
6. **事件计数暂不参与云端同步** —— `counters` / `counter_ticks` 只在本机；worker 的实体白名单里没有这两张表。
   大屏和电脑端是两台机器时，教室里记的事件不会出现在办公室那台。两个事件页的副标题都把这件事写在明面上
   （「事件只记在本机，暂不参与云端同步」/「只统计本机记录」），避免老师看到一片 0 以为数据丢了。
   单机使用、或两台机器共用一份库（`--db` 指向网盘/共享目录）的用法不受影响。
7. **`*.workers.dev` 默认域名在部分国内网络下不通**（代理 `CONNECT` 返回 502），所以生产必须挂自有域名
   （`[[routes]] custom_domain = true`，写法见 `worker/wrangler.toml`）。用的人多了以后要换域名，
   记得**旧路由先留一段时间**：删掉的那一刻，所有填了旧地址的机器会同时同步不了，而用户不知道该去改哪里。

## 六、上线步骤（最省事的顺序）

1. **在家里**先配好云端：按 `worker/README.md` 走一遍 `wrangler login` → `d1 create` → 填 `database_id` →
   `migrations apply --remote` → `secret put TOKEN_SECRET` → `deploy`，拿到地址（几分钟，免费额度足够）。
2. 电脑端 `设置 → 同步` 建班，拿到 8 位班级码；再到 `设置 → 预配置` 填班级名、座位布局、分值方案（加分项默认三个，可改），
   点「导出配置包」得到 `.cpcfg`（建议加口令），拷到 U 盘 —— **基础配置到此结束，剩下的都不需要在教室做**。
3. `scripts/publish.ps1` 打出 `dist/ClassPoints-win-x64/`（370 文件 / 195.6 MB）并顺带生成同名 zip，
   整个目录拷到教室那台机器；不想自己编就用 GitHub Actions 的构建产物（`Actions → 选一次构建 → Artifacts`，
   需要登录，14 天过期），或者按 `README` 里「可选：把发布包托管到 CNB」配一条固定链接；
4. 教室机器上双击「启动.cmd」，第一步选「教室大屏」，第二步「预配置」选 U 盘里那个 `.cpcfg`
   （填口令 → 套用，包里有的项后面自动跳过），然后只做三件事：贴名单、确认分值、设 6 位管理密码并拿到恢复码。
   形态和配置包都记在本机，以后双击就直接进大屏，不用再记任何命令行参数。
5. 办公室电脑同样拷一份，启动时选「班主任电脑」；想让学生自己在走廊那台机器上查，就选「只读查询」——
   只读端没有任何写入口，连会话都不建、读卡器都不启。`设置 → 备份` 指到网盘目录。

不接云端也完全可用 —— 纯本地模式下备份就是同步，换机器用「整包导出 / 导入」。
